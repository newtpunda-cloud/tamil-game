# மண் வாசம் — திறந்த உலகம்

A Tamil-language, procedural 3D open-world driving and exploration game inspired by Tamil Nadu.

## Run locally

```powershell
python -m pip install "streamlit>=1.57"
streamlit run app.py
```

Open the local URL printed by Streamlit. Use **WASD** or the arrow keys to drive or walk, **E** to enter or exit the car, and **F** to interact with nearby characters. While walking, click and move the mouse to look around.

The world, vehicle, characters, roads, houses, and vegetation are generated in the app with WebGL; no external 3D assets are required.
